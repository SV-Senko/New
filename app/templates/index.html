SwitchOps Web

Автоматизация работы над коммутаторами через SSH, Telnet и SNMP.

Быстрый запуск

  1. Настройте драйверы подключений.
  2. Подключите инвентарь устройств.
  3. Запустите массовые операции через API.

Пример API-запроса

POST /api/execute
{
  "protocol": "ssh",
  "host": "10.0.0.10",
  "username": "admin",
  "password": "secret",
  "command": "show version"
}
